# Volley.Point

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

## Описание проекта

**Volley.Point** — учебный многостраничный HTML/CSS-сайт интернет-магазина
товаров для волейбола. В ассортименте — мячи для классического и пляжного
волейбола, наколенники, табло для судейства.

Проект выполнен без CSS-фреймворков. JavaScript используется минимально —
только для открытия и закрытия модального окна с формой заявки.

## Ссылка на опубликованный проект

GitHub Pages: **https://alekseeeeeeenkova.github.io/kr1-html-css-shop/**

## Структура проекта

- `index.html` — главная страница: hero-блок, популярные товары;
- `catalog.html` — каталог товаров с фильтрами;
- `product-1.html` — карточка товара «Мяч Mikasa V200W»;
- `product-2.html` — карточка товара «Мяч Mikasa V300W»;
- `product-3.html` — карточка товара «Мяч пляжный Mikasa BV550C Beach PRO»;
- `product-4.html` — карточка товара «Наколенники ASICS» (с выбором цвета и размера);
- `product-5.html` — карточка товара «Табло для волейбола перекидное»;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `about.html` — о магазине;
- `delivery.html` — доставка и оплата;
- `css/style.css` — файл стилей;
- `js/main.js` — минимальный JS для модального окна и валидации формы;
- `images/` — папка с изображениями товаров и hero-картинкой;
- `README.md` — описание проекта;
- `.gitignore` — список исключённых файлов.

## Обязательные страницы

- **Главная** (`index.html`) — hero-блок с фоновой картинкой, популярные товары.
- **Каталог** (`catalog.html`) — 5 карточек товаров, блок фильтров.
- **Карточка товара** (`product-1.html` … `product-5.html`) — изображение, описание, таблица характеристик, кнопки «Заказать» и «Вернуться в каталог».
- **Заявка** (`order.html`) — форма оформления заявки.
- **Контакты** (`contacts.html`) — контактная информация.
- **О нас** (`about.html`) — информация о магазине.
- **Доставка и оплата** (`delivery.html`) — способы доставки и оплаты (таблица).

## Реализованные элементы интерфейса

- карточки товаров с фотографиями;
- кнопки «Заказать» и «Подробнее»;
- бейджи «Хит» и «Новинка»;
- модальное окно с формой заявки;
- HTML-валидация формы (`required`, `minlength`, `pattern`, `type="email"`);
- JS-обработка формы: проверка, сообщение об успехе;
- таблица характеристик на страницах товаров;
- блок фильтров на странице каталога;
- sticky-шапка сайта;
- всплывающее окно с контактами (кнопка-мяч в правом нижнем углу);
- hero-блок с фоновой картинкой.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root` (6 цветов);
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

- **Flexbox** — для шапки, основного меню, внутренней структуры карточек;
- **CSS Grid** — для сетки карточек товаров и страницы каталога (фильтры + товары).

## БЭМ-структура

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка;
- `site-nav` — навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — страница товара;
- `catalog-layout` — структура каталога;
- `catalog-filters` — фильтры;
- `order-dialog` — модальное окно;
- `order-form` — форма заявки;
- `button` — кнопка;
- `chat-button` и `chat-popup` — кнопка-мяч и чат-окно;
- `product-table` — таблица характеристик.

## Позиционирование

В проекте показано базовое позиционирование:

- `position: sticky` — для шапки сайта;
- `position: fixed` — для кнопки-мяча и модального окна;
- `position: absolute` — для бейджа «Хит»/«Новинка» в углу карточки;
- `z-index` — для шапки (100), кнопки-мяча (90) и модального окна (1000).
