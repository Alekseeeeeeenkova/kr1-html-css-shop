# Учебный frontend-проект

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

## Описание проекта

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина
или каталога услуг. Проект выполнен без CSS-фреймворков и без полноценной
JavaScript-интерактивности. Основная задача — показать владение HTML, CSS,
семантической разметкой, многостраничной структурой сайта, базовыми формами,
модальным окном, навигацией, Flex/Grid и БЭМ.

## Ссылка на опубликованный проект

GitHub Pages: https://alekseeeeeeenkova.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` – главная страница: hero-блок, преимущества, популярные товары;
- `catalog.html` – каталог товаров: карточки, фильтры;
- `product.html` – карточка товара: изображение, описание, характеристики, цена;
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – минимальный JS для модального окна и валидации формы;
- `images/` – папка для изображений;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Обязательные страницы

- **Главная** (`index.html`) — hero-блок, преимущества, популярные товары.
- **Каталог** (`catalog.html`) — карточки товаров, блок фильтров.
- **Карточка товара** (`product.html`) — описание, характеристики, таблица, кнопка заявки.
- **Заявка** (`order.html`) — форма оформления заявки.
- **Контакты** (`contacts.html`) — контактная информация и ссылка на форму.

## Используемые технологии

- HTML5 — семантическая разметка;
- CSS3 — переменные, состояния, Flexbox, CSS Grid, БЭМ;
- JavaScript — минимальная логика для модального окна и валидации формы;
- Git и GitHub — контроль версий;
- GitHub Pages — публикация проекта.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- таблица характеристик товара;
- блок фильтров на странице каталога;
- sticky-шапка сайта;
- фиксированная кнопка «Наверх».

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Позиционирование

В проекте показано базовое позиционирование:

- `position: sticky` — для шапки сайта;
- `position: fixed` — для кнопки «Наверх» и модального окна;
- `z-index` — для шапки, кнопки «Наверх» и модального окна.
